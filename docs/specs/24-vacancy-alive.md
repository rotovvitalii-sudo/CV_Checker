# W2 · «Вакансия ещё живая?» — проверка до адаптации CV

**Приоритет:** Must · **Зависит от:** адаптеры систем найма (`job-search/edtech.py`), C11 (`web/autofill.js` → `applyTarget`)
**Оценка:** ~0,5 дня · **Источник:** воркбук, блок 2 («Вакансії, яких може не бути»); случай Lingua 2026-10-16.

## Problem Statement
Часть объявлений не ведёт к найму: вакансию закрыли, найм на паузе, компания собирает базу. Мы уже собрали CV и
письмо под Lingua, а форма ответила «Job not found». Адаптация CV стоит ≈ $0,5–1 и время на надиктовку письма —
на мёртвую вакансию это выброшено.

## Goals
1. Перед «Адаптировать CV» и «Сгенерировать письмо» статус вакансии проверяется за ≤ 5 секунд, бесплатно (без агента).
2. Закрытая вакансия не запускает платный шаг без явного подтверждения — 0 случаев «CV под закрытую вакансию» без предупреждения.
3. Старые объявления (> 45 дней) помечаются «проверь, что живая».

## Non-Goals
- **Проверка вакансий LinkedIn и сайтов с логином** — нет открытого API; только дата публикации.
- **Автоархив закрытых заявок** — решение за тобой, приложение только предлагает.
- **Опрос всех заявок каждый день** — проверка по требованию и раз в сутки для активных (P1).

## User Stories
- Как кандидат, я хочу перед адаптацией CV видеть «вакансия открыта / закрыта / не проверить», чтобы не тратить деньги впустую.
- Как кандидат, я хочу видеть «опубликована 3 месяца назад, описания команды нет — проверь на сайте компании».
- *Крайний случай:* API системы найма не ответил — статус «не проверить», кнопки работают как раньше.

## Requirements
### P0
- **P0-1. `web/alive.js`:** по ссылке вакансии (Ashby, Lever, Greenhouse, Workable, SmartRecruiters, Recruitee, Personio)
  проверяет, есть ли вакансия в открытом списке компании (те же API, что в `edtech.py`); иначе — HTTP-статус и маркеры
  «job not found / no longer accepting» на странице. Результат кэшируется на 12 часов: `open | closed | unknown`, `checkedAt`.
- **P0-2. Возраст объявления:** `date_posted` фита; > 45 дней — пометка «старое объявление».
- **P0-3. Перед «Адаптировать CV», «Сгенерировать письмо», «Заполнить заявку»:** если `closed` — диалог «Вакансия
  закрыта на сайте. Всё равно?» с кнопкой «В архив».
- **P0-4. Показ** в шапке заявки: «● открыта · проверено 2 ч назад» / «закрыта» / «не проверить» + «Проверить снова».
- ✅ Lingua (закрыта) и Voxa (открыта) определяются правильно.

### P1
- Раз в сутки — проверка активных заявок (new, ready); закрытые → уведомление C3 «Вакансия X закрылась».
- В ленте (S1, S6, S7) уже закрытые вакансии не показываются (для EdTech/FinTech это уже так — последний снимок).

## Success Metrics
- **Leading:** 0 адаптаций CV под закрытые вакансии без подтверждения; проверка ≤ 5 с.
- **Lagging:** условная стоимость на отправленную заявку (S5) снижается.
