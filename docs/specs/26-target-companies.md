# W4 · Список компаний, контакты и первое сообщение

**Приоритет:** Should · **Зависит от:** S6/S7 (базы компаний и опрос карьерных страниц), C3 (уведомления)
**Оценка:** ~1,5 дня · **Источник:** воркбук, блок 2 («Список компаній», «Карта контактів»).

## Problem Statement
По данным Ashby (250 000 наймов, воркбук), рекомендации дают ~1% заявок, но **17–18% наймов**. В CV Checker нет
ничего про людей: только отклики. Воркбук предлагает список из 15 компаний мечты с еженедельной проверкой вакансий
и карту контактов: кто внутри или может познакомить, плюс первое сообщение «кто я, почему вам, один вопрос» — без
просьбы о работе.

## Goals
1. Список до 15 целевых компаний: чем интересна, контакты, статус общения — в приложении, а не в голове.
2. Новая вакансия в целевой компании видна в течение суток (для компаний с открытым API — автоматически).
3. Первое сообщение контакту — черновик за ≤ 1 минуту, ≤ 3 предложения, без просьбы о работе.
4. ≥ 2 разговора с людьми из целевых компаний в неделю (метрика твоих действий, W7).

## Non-Goals
- **Отправка сообщений из приложения** (LinkedIn, email) — пишешь сам; принцип «ничего не отправлять от моего имени».
- **Импорт контактов из LinkedIn** — нет API, правила площадки.
- **CRM для рекрутеров** — только целевые компании и люди в них.

## User Stories
- Как кандидат, я хочу добавить компанию в «Целевые» (из ленты, базы EdTech/FinTech или вручную) и записать, чем она интересна.
- Как кандидат, я хочу записать контакты: имя, роль, круг (близкий / знакомый / незнакомый), ссылка, статус (не писал → написал → поговорили → рекомендовал).
- Как кандидат, я хочу получить черновик первого сообщения под контакт и компанию — по формуле воркбука.
- Как кандидат, я хочу ответить рекрутеру с неинтересной вакансией шаблоном «спасибо, ищу роль X, домен Y, задачу Z».
- *Крайний случай:* у компании нет открытого API — ссылка на страницу карьеры и напоминание «проверь раз в неделю».

## Requirements
### P0
- **P0-1. Экран «Компании»** (`#/companies` или вкладка в «Поиск вакансий»): до 15 целевых, поля — компания, чем интересна,
  страница карьеры, открытые вакансии сейчас, контакты, последняя активность.
- **P0-2. Добавить в целевые** из карточки ленты, базы компаний S6/S7 и вручную; для компаний с API — открытые вакансии подтягиваются
  тем же сборщиком (`edtech.py`), новые → уведомление C3.
- **P0-3. Контакты:** имя, роль, круг, ссылка, статус, заметка; хранение `web/data/targets.json`.
- **P0-4. Черновик первого сообщения** (агент, Sonnet, ≈ $0,05–0,1): вход — компания, контакт, вакансия (если есть), профиль;
  формула «кто я → почему пишу вам → один конкретный вопрос», ≤ 3 предложения, язык контакта; humanizer. Кнопка «Скопировать».
- ✅ Сообщение не содержит просьбы о работе и рекомендации (проверка по словарю).

### P1
- Шаблон ответа рекрутеру с неинтересной вакансией (без агента, из профиля поиска).
- Напоминание «написать ещё раз» через 7 дней без ответа (как фоллоу-ап M1).
- Заявка в целевую компанию помечается «есть контакт» — в статистике (S3) разрез «с контактом / без».

### P2
- Связь контакта с заявкой: «рекомендовал» → канал отправки «Реферал».

## Success Metrics
- **Leading:** 15 компаний в списке за неделю; ≥ 2 сообщения в неделю.
- **Lagging:** доля ответов на заявки «с контактом» выше, чем «без» (S3).
