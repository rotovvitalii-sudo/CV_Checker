# C1 · Поиск и фильтры

**Приоритет:** Could · **Зависит от:** — (полезнее после S1 и роста числа заявок)
**Аналог в Aircareer:** поиск «Search roles, companies» и фильтры Location / Remote / Salary / Type /
Experience / Posted, «Clear all», сортировка «Best match»

## Problem Statement
Пока заявок 4, хватает трёх сегментов «Активные / Отправленные / Архив». Когда их станет 20+ (а с
лентой S1 — сотни карточек), найти конкретную компанию или отсеять неподходящий формат без поиска
и фильтров станет медленно.

## Goals
1. Найти заявку по компании или роли — ≤ 3 секунды при 100+ записях.
2. Отфильтровать по формату, наличию зарплаты, seniority и давности — одним-двумя кликами.
3. Фильтры одинаково работают в таблице заявок и в ленте.

## Non-Goals
- **Серверный поиск и индексы** — данных мало, фильтруем на клиенте.
- **Сохранённые поиски и алерты** — C3 / v2.
- **Фильтр по зарплатной вилке числом** — зарплаты в разных валютах и форматах; только «указана / нет».

## User Stories
- Как кандидат, я хочу искать по компании или роли в таблице и ленте.
- Как кандидат, я хочу фильтровать по формату (удалённо / гибрид / офис), «зарплата указана»,
  seniority, давности публикации и диапазону фита.
- Как кандидат, я хочу сортировать по фиту, матчу с Master CV или дате.
- Как кандидат, я хочу сбросить все фильтры одной кнопкой и видеть число результатов.
- *Крайний случай:* фильтр дал 0 — пустое состояние с кнопкой «Сбросить фильтры».

## Requirements

### P0
**P0-1. Строка поиска** над таблицей «Все заявки» (по роли, компании, локации; без учёта регистра).
**P0-2. Фильтры-чипы:** формат · зарплата указана · seniority · фит (≥ 7 / 5–6 / < 5) · давность
(24 ч / 3 дня / неделя / месяц). «Сбросить все». Состояние в URL (`#/?q=…&fmt=remote`).
**P0-3. Сортировка:** фит / матч с Master / дата добавления / дата отправки.
- ✅ Комбинация фильтров даёт тот же результат после перезагрузки (из URL).
**P0-4.** Те же компоненты на экране ленты (S1), если он есть.

### P1
- Счётчики у значений фильтра («Удалённо · 12»).
- Сохранение последнего набора фильтров.

### P2
- Фильтр по языку вакансии и по наличию задачи «обучение» (сигнал `classify.py`).

локации (remote / hybrid / иначе офис). P1 (счётчики у значений) — не сделано.
