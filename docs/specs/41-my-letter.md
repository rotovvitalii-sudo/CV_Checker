# C16 · Своё сопроводительное письмо: вставил и сохранил

**Приоритет:** Should · **Зависит от:** C8 / C10 (письмо, «Прежнее письмо», файлы для формы), C13 (факты из текста), S3 (статистика)

## Problem Statement
Письмо можно было получить только двумя путями: из надиктовки или сгенерировать. Письмо, написанное самим кандидатом, положить в заявку было нельзя.

## Что сделано
- В блоке письма — «Вставить своё письмо» / «Изменить своё письмо»: поле, «Сохранить». CV для этого не нужно.
- `POST /api/vacancies/:name/letter-mine {text}`: текст дословно в `Cover Letter.md`, `letter-summary.json → mode: 'mine'`, прошлое письмо — в «Прежнее письмо», трассировки удаляются, файлы для формы (PDF, DOCX) пересобираются.
- Правила «≥ 80% надиктовки» и «факты с источником» не применяются; humanizer считается, но не показывается и не спрашивается при скачивании.
- При отправке `sent.letterMode: 'mine'`, в «Статистике» — разрез «Моё письмо». Заявка `new` становится `ready`.
- Факты — поток C13 (`origin: 'myletter'`, ответ ≥ 40 слов): новые факты в «Предложено добавить», целая история — «сделать кейсом», в базу только по «Добавить». Сырой текст — `knowledge-base/raw/<дата>-letter-mine-<slug>.md`: виден в «Надиктовках писем», попадает в голосовой профиль при следующем обновлении.

## Статус
✅ Готово (2026-11-06). Проверено в песочнице: сохранение дословно, пустой текст — отказ, PDF на 1 страницу, факты с цитатами и «в базе этого нет», «вернуть» в обе стороны, короткое письмо (10 слов) — без разбора, интерфейс без ошибок. Разрез в статистике и `sent.letterMode` — только по коду.
