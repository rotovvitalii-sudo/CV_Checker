# C5 · Каталог сайтов вакансий

**Приоритет:** Could · **Зависит от:** S1 (экран «Поиск вакансий»), C4 и диалог «+ Вакансия» (добавить найденное)
**Оценка:** ~0,5 дня
**Источник:** запрос кандидата 2026-10-14.

**Решения (подтверждены):**
- ссылка ведёт на **главную страницу раздела вакансий** сайта, поиск — вручную;
- приложение отмечает, **когда сайт смотрели последний раз**, и подсвечивает давно не открытые;
- рынки: **Польша, Украина, глобальные и remote, отраслевые (EdTech, FinTech, Web3)**.

## Problem Statement
Лента (S1, S6, S7) собирает только то, что отдают открытые API. Большая часть рынка живёт на сайтах
с логином (LinkedIn, Pracuj.pl, Djinni), которые приложение не обходит и не должно обходить. Сейчас
список этих сайтов держится в голове: какие-то проверяются каждый день, какие-то забываются на недели,
и сильные вакансии на них проходят мимо.

## Goals
1. Все 20 сайтов открываются из приложения в один клик, в новой вкладке браузера, где ты уже залогинен.
2. Видно, какой сайт давно не смотрел: каждый сайт открыт хотя бы раз за 7 дней.
3. Вакансия, найденная на сайте, попадает в приложение за ≤ 30 секунд через существующий «+ Вакансия».

## Non-Goals
- **Сбор вакансий с этих сайтов** (скрейпинг, агент в браузере): запрещено правилами LinkedIn и
  других площадок, плюс нужны логин и обход защиты от ботов.
- **Хранение логинов и паролей, автологин:** вход — в твоём браузере, приложение паролей не видит.
- **Встраивание сайтов внутрь приложения (iframe):** площадки это блокируют.
- **Готовые поисковые запросы в ссылках:** решено вести на главную страницу вакансий. Можно добавить
  позже (P2).
- **hh.ru, hh.kz и другие российские площадки:** правило проекта «без российских и китайских компаний».

## User Stories
- Как кандидат, я хочу открыть «Поиск вакансий → Сайты» и видеть 20 площадок по группам, чтобы не
  держать список в голове.
- Как кандидат, я хочу кликнуть по сайту и попасть на его страницу вакансий в новой вкладке.
- Как кандидат, я хочу видеть у каждого сайта «смотрел 3 дня назад» и подсвеченные сайты, которые
  не открывал больше 7 дней, чтобы обходить всё по кругу.
- Как кандидат, я хочу из этого же экрана добавить найденную вакансию (ссылка или текст), чтобы она
  ушла в фит и заявки.
- *Крайний случай:* сайт ни разу не открывался — пометка «ещё не смотрел» и подсветка.
- *Крайний случай:* ссылка на LinkedIn не открывается приложением при добавлении вакансии (нужен логин)
  — действует текущее правило: просить вставить текст.

## Requirements

### P0
**P0-1. Каталог `web/data/job-sites.json`** — 20 сайтов, запись `{id, name, url, group, note, login}`:
- **Глобальные и remote (6):** LinkedIn Jobs, Indeed, Glassdoor, Wellfound, Welcome to the Jungle, We Work Remotely;
- **Польша (5):** Pracuj.pl, Just Join IT, No Fluff Jobs, theprotocol.it, RocketJobs;
- **Украина (4):** Djinni, DOU, Work.ua, Robota.ua;
- **Отраслевые (5):** EdSurge Jobs (EdTech), eFinancialCareers (FinTech), CryptoJobsList, Web3.career,
  Cryptocurrency Jobs (Web3).
- `note` — одна строка, зачем этот сайт (например, «Djinni — анонимный профиль, рекрутеры пишут сами»).
- `login` — нужен ли вход, чтобы видеть вакансии или откликаться.
- ✅ Каждая ссылка при реализации открыта вручную в браузере и ведёт на страницу вакансий, а не на ошибку.

**P0-2. Вкладка «Сайты»** в «Поиск вакансий» (рядом с «Пропущенные»):
- плитки по 4 группам: название, строка-пояснение, пометка «нужен вход», «смотрел N дней назад»;
- клик открывает сайт в новой вкладке (`target="_blank" rel="noopener"`) и записывает время открытия;
- сайты, не открытые больше 7 дней или ни разу, подсвечены; сверху счётчик «давно не смотрел: N».
- ✅ После клика отметка обновляется без перезагрузки и сохраняется после перезапуска сервера.

**P0-3. Отметки посещений** — `web/data/job-sites-visits.json` (`{id: ISO-время}`), `POST /api/job-sites/:id/visit`,
`GET /api/job-sites` отдаёт каталог вместе с отметками.

**P0-4. «Добавить найденную вакансию»** — кнопка на вкладке открывает существующий диалог «+ Вакансия».

### P1
- Источник найденной вакансии: если диалог открыт с вкладки «Сайты» сразу после клика по сайту,
  поле «канал» (M1) заполняется названием этого сайта. Так статистика S3 покажет, с каких сайтов
  приходят ответы.
- Добавить, скрыть, переименовать сайт прямо на вкладке (без правки файла).

### P2
- Готовые поисковые ссылки («Product Lead», удалёнка, Польша) с редактируемым запросом.
- Свой интервал проверки для каждого сайта (LinkedIn — каждый день, отраслевые — раз в неделю).

## Что уже есть в коде
- Экран и вкладки ленты: `web/public/app.js` → `renderFeed()`, `feedTab`; стили вкладок и плиток.
- Диалог «+ Вакансия» (ссылка, текст, «Уже отправил»): `web/public/app.js`.
- Хранение данных приложения: `web/data/*.json`, сервер `web/server.js`.

## Success Metrics
- **Leading (2 недели):** каждый из 20 сайтов открыт хотя бы раз; счётчик «давно не смотрел» ≤ 3
  в обычный день.
- **Lagging (месяц):** ≥ 5 заявок с каналом с одного из сайтов каталога (по разрезу S3).

## Open Questions
- *(ты, неблокирующий)* 7 дней как порог «давно не смотрел» — одинаково для всех сайтов? Свой интервал
  на сайт отложен в P2.

## Timeline
~0,5 дня: каталог и проверка ссылок → API отметок → вкладка «Сайты» → кнопка «Добавить найденную».

## Статус (2026-10-14)
P0 и P1 сделаны.
- `web/sites.js`: каталог и отметки посещений в одном файле `web/data/job-sites.json` (`{sites, visits}`;
  создаётся из списка по умолчанию при первом запуске). API: `GET /api/job-sites`, `POST /api/job-sites/:id/visit`,
  `POST /api/job-sites` (свой сайт), `PATCH /api/job-sites/:id` (название, ссылка, пояснение, «нужен вход», скрыть),
  `DELETE /api/job-sites/:id` (только свои сайты; сайты каталога скрываются).
- Вкладка «Поиск вакансий → Сайты»: 4 группы + «Свои», подсветка сайтов, не открытых больше 7 дней,
  счётчик «давно не смотрел», «Добавить найденную вакансию», «+ Свой сайт», «показать скрытые».
- Диалог «+ Вакансия»: поле «Где нашёл». С вкладки «Сайты» в нём уже выбран последний открытый сайт
  (если открыт меньше 3 часов назад). На вкладке «Уже отправил» канал ставится сам: LinkedIn → «LinkedIn»,
  остальные сайты → новый канал **«Сайт вакансий»**. Заявка хранит `foundOn`; диалог отправки (M1) берёт
  канал оттуда; в статистике (S3) новый разрез «Где нашёл вакансию».
- Ссылки проверены 2026-10-14. EdSurge Jobs переехал на `jobsboard.edsurge.com`. No Fluff Jobs не открывается
  во встроенном браузере Claude (блок CloudFront), в обычном браузере работает.
