## Won't (в этот раз)
- **Auto Apply — агент сам отправляет заявки.** Противоречит принципу «ничего не отправлять» и
  правилам площадок. Аналог у нас — M1 + S4: агент готовит, отправляешь ты.
- **Inbox со своим почтовым адресом.** Нужен почтовый сервер. Позже — через Gmail-коннектор.
- **Подписка, лимиты, Pro.** Инструмент личный.
- **Свайп-жест и логотипы компаний.** Кнопки Save / Skip решают ту же задачу.
