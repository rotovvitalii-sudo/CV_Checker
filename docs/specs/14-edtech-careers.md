# Спека S6 · Раздел «EdTech» в поиске вакансий

**Приоритет:** Should · **Зависит от:** S1 (лента, пропуски, «Сохранить» → фит)
**Решения (подтверждены):**
- ежедневный сбор — скрипт по открытым API систем найма; агент только собирает и расширяет базу компаний;
- база на старте — весь мир, около 150 компаний;
- роли — продукт, рост и маркетинг продукта, бизнес и рынки, операции и контент-продукт.

## Problem Statement
Все три прошлых найма случились в компаниях, которые строили обучение, и EdTech — домен, где фит
Кандидата по задаче самый высокий. Но открытые доски (Himalayas, RemoteOK) почти не дают продуктовых
EdTech-ролей: замер на 1315 вакансиях — 0 в потоке A. Вакансии EdTech-компаний живут на их
собственных страницах карьеры. Обходить 150 сайтов вручную каждый день нереально, поэтому сильные
роли проходят мимо.

## Goals
1. Одной кнопкой (≤ 3 минуты) видеть актуальные продуктовые и бизнес-вакансии ~150 EdTech-компаний мира.
2. ≥ 80% компаний базы опрашиваются автоматически через открытый API их системы найма; остальные
   видны списком со ссылкой «проверь вручную».
3. Пропущенная или сохранённая вакансия больше не появляется в разделе — 100% случаев.
4. Ежедневное обновление бесплатно (без агента); агент тратится только на сбор и расширение базы.

## Non-Goals
- **Агент, который каждый день читает 150 сайтов** — долго, дорого (условно $5–20 за обход) и хрупко.
- **Workday, Taleo, Successfactors и свои сайты без API** — их не парсим. Компания остаётся в базе
  со ссылкой на страницу карьеры и пометкой «без API — проверь вручную».
- **LinkedIn** — запрещено правилами площадки.
- **Автоматический фит всех вакансий** — как в S1: фит запускается только по «Сохранить».
- **Фильтры по формату и локации внутри раздела** — это C1, общий для всей ленты.

## User Stories
- Как кандидат, я хочу открыть «Поиск вакансий → EdTech», нажать «Обновить» и увидеть свежие
  продуктовые и бизнес-роли EdTech-компаний со всего мира.
- Как кандидат, я хочу, чтобы обновление ленты раз в день подтягивало и EdTech-вакансии, без
  отдельного действия.
- Как кандидат, я хочу сохранить вакансию (→ фит → заявка) или пропустить её. После этого она больше
  не появляется — ни в EdTech, ни в остальной ленте.
- Как кандидат, я хочу видеть базу компаний: сколько их, у скольких работает автосбор, у кого нет API.
- Как кандидат, я хочу попросить агента расширить базу: найти новые EdTech-компании и их страницы карьеры.
- *Крайний случай:* система найма компании не отвечает или сменилась — компания помечается
  «сломалась», обновление остальных не прерывается.
- *Крайний случай:* одна вакансия пришла и из EdTech, и с Himalayas — показывается один раз.

## Requirements

### P0
**P0-1. База компаний `job-search/edtech/companies.json`.**
- Запись: `{name, country, segment, careers_url, ats, token, status, checked_at, jobs_last}`.
- `segment`: consumer / языки / K-12 / higher-ed / LMS и курсы / corporate learning / финобразование.
- `ats`: greenhouse | lever | ashby | workable | smartrecruiters | recruitee | personio | none.
- `status`: ok | no_api | broken.
- ✅ После первого сбора в базе ≥ 120 компаний, у ≥ 80% `status: ok`.

**P0-2. Скил и задача агента «Собрать / расширить базу»** — новый `.claude/skills/edtech-companies/SKILL.md`.
- Агент находит EdTech-компании по сегментам и регионам (Европа, США, LatAm, Азия), открывает
  их страницу карьеры, определяет систему найма и токен. Проверяет токен одним запросом к API и
  дописывает в базу без дублей.
- За один запуск — до 50 новых компаний, чтобы задача укладывалась в 15–20 минут. Первый сбор —
  3 запуска.
- Запуск из приложения: кнопка «Найти новые компании», через `agentReady`, пишется в журнал агента (S5).
- ✅ Ни одна запись не добавляется без проверенного ответа API или без пометки `no_api`.

**P0-3. Ежедневный сборщик `job-search/edtech_fetch.py`** (без агента):
- Для каждой компании со `status: ok` вызывает открытый API её системы найма:
  - Greenhouse `boards-api.greenhouse.io/v1/boards/{token}/jobs?content=true`
  - Lever `api.lever.co/v0/postings/{token}?mode=json`
  - Ashby `api.ashbyhq.com/posting-api/job-board/{token}`
  - Workable `apply.workable.com/api/v1/widget/accounts/{token}`
  - SmartRecruiters `api.smartrecruiters.com/v1/companies/{token}/postings`
  - Recruitee `{token}.recruitee.com/api/offers/`
  - Personio `{token}.jobs.personio.de/xml`
- Пауза 0,3 с между компаниями, тот же User-Agent, что у `fetch.py`.
- Приводит к общему формату сырья (`title, company, url, location, date_posted, description, source: "edtech", segment`).
- Отбирает роли по заголовку новыми списками в `job-search/classify.py` (единственное место
  критериев): `ROLE_PRODUCT` (есть) + `ROLE_GROWTH`, `ROLE_BUSINESS`, `ROLE_OPS_EDU`.
- Пишет `job-search/raw/edtech-<дата>.json` (только отобранные) и обновляет у компаний
  `checked_at`, `jobs_last`, `status` (ошибка → `broken`).
- ✅ 150 компаний обходятся ≤ 3 минут; сбой одной компании не прерывает обход.

**P0-4. Раздел «EdTech» в ленте** — вкладка «EdTech · N» рядом с «Подходят» и «Продуктовые роли».
- `job-search/feed.py` кладёт вакансии `source: edtech` в раздел `edtech`.
- Те же исключения, что в S1: уже сохранённые (vacancies, корпус, входящие) и пропущенные
  (`web/data/feed-skipped.json`), дедуп по URL.
- Карточка как в ленте, плюс сегмент и страна компании. Кнопки «Сохранить», «Пропустить»,
  «Открыть на сайте ↗».
- Пустое состояние: «Новых EdTech-вакансий нет. Последнее обновление: …».

**P0-5. Обновление.**
- Кнопка «Обновить EdTech» во вкладке запускает `edtech_fetch.py` с прогрессом по компаниям (SSE, как в S1).
- Общая «Обновить ленту» запускает и `fetch.py --fresh`, и `edtech_fetch.py`.
- ✅ Итог «+N новых EdTech-вакансий» после обновления.

**P0-6. Блок «База компаний»** (свёрнут) во вкладке EdTech:
- «148 компаний · автосбор 131 · без API 12 · сломались 5», кнопка «Найти новые компании»;
- раскрывается в таблицу: компания, страна, сегмент, система найма, статус, вакансий в последний
  раз, ссылка на страницу карьеры.

### P1
- Бейдж «новые с прошлого обновления» на карточках и счётчик в меню.
- Добавить компанию вручную (название + ссылка на карьеру) → агент определяет систему найма.
- Автообновление EdTech раз в день при первом открытии ленты.

### P2
- Сигнал потока B из EdTech-базы: компания открыла роль «Head of Learning / Academy» без продакта.
- Уведомление о новой сильной EdTech-вакансии (C3).

## Что уже есть в коде

  `web/feed.js`, `/api/feed*`, экран `#/feed` (S1).
- Словарь ролей: `job-search/classify.py` → `ROLE_PRODUCT`; калибровка — `job-search/calibrate_dict.py`.
- Формат сырья и User-Agent: `job-search/fetch.py` → `norm()`, `UA`.
- Фоновые задачи агента, `agentReady`, журнал: `web/agent.js`, `web/runs.js`.

## Success Metrics
- **Leading (неделя):** ≥ 120 компаний в базе, ≥ 80% с автосбором; обновление ≤ 3 мин;
  ≥ 10 продуктовых и бизнес-ролей в разделе за неделю.
- **Lagging (месяц):** ≥ 3 заявки из раздела EdTech; доля фитов ≥ 7 среди сохранённых из EdTech
  выше, чем у остальной ленты.

## Статус и цифры (2026-10-13)
- **Сделано P0.** `job-search/edtech.py` (адаптеры 7 систем найма, `seed` / `add` / `fetch` / `list`),
  база `job-search/edtech/companies.json`, стартовый список `job-search/edtech/seed.json` (175 компаний),
  роли — `edtech_role()` и списки `ROLE_GROWTH` / `ROLE_BUSINESS` / `ROLE_OPS_EDU` / `EXCLUDE_LEVEL`
  в `classify.py` + 27 фикстур в `job-search/fixtures/edtech_roles.json`; скил
  `.claude/skills/edtech-companies/`; вкладка «EdTech» с кнопкой «Обновить EdTech» и блоком
  «База компаний» с кнопкой «Найти новые компании».
- **Отличие от плана — первая база собрана не агентом, а пробником** `edtech.py seed`: перебор токенов
  во всех системах найма, 175 компаний за 80 секунд, бесплатно. Агент — только для расширения.
- **Проверка принадлежности доски компании.** Одного ответа API мало. Нужны открытые вакансии плюс
  совпадение названия доски (Greenhouse, Workable) или не меньше 5 строгих упоминаний темы обучения
  в описаниях (английский, немецкий, испанский, португальский). Отсеяло ложные совпадения: AKQA Leap,
  платёжный Imprint, психотерапевтический Headway, пустые аккаунты Workable.
- **Покрытие: 57 из 175 (33%) с автосбором** — ниже цели 80%. Остальные — Workday или свои сайты,
  0 открытых вакансий в момент проверки, неугаданный токен. Пробный запуск агента на 5 компаниях:
  +2 к автосбору, 118 с, ≈ $1.16 → 30 компаний ≈ $5–8.
- **Обновление: 57 компаний за 6–26 с**, 78 подходящих ролей у 29 компаний (после склейки одной вакансии
  в нескольких городах). Шум (BDR/SDR, specialist, counsel, data scientist, TPM, канальный маркетинг)
  отсечён словарём после ревью 132 заголовков.
