# C4 · Ручная заявка без конвейера

**Приоритет:** Could · **Зависит от:** M1 (запись отправки), S3 (смысл — полная статистика)
**Аналог в Aircareer:** Applications → «+ Add application»

## Problem Statement
Часть откликов делается вне приложения: «Easy Apply» в LinkedIn с базовым CV, реферал, быстрый
отклик с телефона. Их нет в CV Checker, поэтому статистика (S3) неполная и сравнение «адаптированное
CV против базового» невозможно — базовых заявок просто нет в данных.

## Goals
1. Добавить уже отправленную заявку — ≤ 30 секунд, без агента.
2. Такие заявки участвуют в доске, фоллоу-апах и статистике наравне с остальными.

## Non-Goals
- **Импорт истории откликов из LinkedIn** — нет API, ручной ввод достаточен.
- **Запуск фита для таких заявок по умолчанию** — можно позже вручную, если вставлен текст.

## User Stories
- Как кандидат, я хочу быстро записать «подался в X на роль Y через LinkedIn сегодня», чтобы
  заявка попала в трекинг.
- Как кандидат, я хочу по желанию приложить ссылку или текст вакансии и запустить фит позже.
- *Крайний случай:* такая компания и роль уже есть — предложить открыть существующую, а не дублировать.

## Requirements

### P0
**P0-1. «Добавить отправленную»** в диалоге «+ Вакансия»: компания, роль, дата, канал, ссылка
(опц.), заметка. Создаёт `vacancies/<Роль - Компания>.md` (минимальный фронтматтер, `source: manual`)
и запись `sent` (M1) с `cvBaseVersion` = актуальная версия Master и пометкой «без пакета».
- ✅ Заявка видна на доске в «Отправлено» и участвует в фоллоу-апах.
- ✅ Дубль по компании + роли — предупреждение.

### P1
- Кнопка «Оценить фит» у таких заявок, если позже вставлен текст вакансии.

### P2
- Массовый ввод (вставить список «компания — роль — дата»).

## Что уже есть в коде
- Создание файла вакансии: `scorer/score_job.py` → `save_vacancy_md()`.
- Список заявок строится по файлам `vacancies/` и `output/`: `web/store.js` → `scan()`.

## Success Metrics
- **Lagging:** в статистике (S3) есть разрез «базовое CV» хотя бы на 5 заявках.

## P1 (2026-10-21)
У ручной заявки без текста вакансии в блоке «Матч» — поле «Вставь текст вакансии» и «Сохранить и оценить фит»
(`POST /api/vacancies/:name/vacancy-text`, ≥ 50 слов): текст пишется в файл вакансии (front matter сохраняется), сразу
запускается фит. Статус «Отправлено» и запись `sent` не меняются.

Плюс (2026-10-21): пока текста вакансии нет, агентные шаги закрыты — «Адаптировать CV», «Извлечь ключи», «Вердикт рекрутера»,
подготовка к собеседованию и ответы на вопросы формы скрыты или неактивны, сервер отвечает 400 без запуска агента.
