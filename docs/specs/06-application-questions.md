# S4 · Ответы на вопросы формы заявки

**Приоритет:** Should · **Зависит от:** — · **Связано с:** `cover-letter`, `humanizer`, база знаний
**Аналог в Aircareer:** часть Auto Apply (заполнение полей) — у нас без отправки

## Problem Statement
Формы заявок почти всегда содержат вопросы помимо CV: «Why do you want to work here?», «Describe a
product you launched», notice period, ожидания по зарплате, разрешение на работу. Каждый раз ответы
пишутся с нуля, в спешке и без опоры на кейсы из базы. Это самая долгая ручная часть подачи после
письма.

## Goals
1. Ответы на 5–8 вопросов формы готовы ≤ 3 минут после вставки вопросов.
2. 100% фактов в ответах прослеживаются до карточек или CV — ноль выдуманного.
3. Фактические вопросы (notice period, зарплата, локация, разрешение на работу) отвечаются из
   профиля одинаково во всех заявках.

## Non-Goals
- **Заполнение формы на сайте** — копируешь сам (принцип «ничего не отправлять»).
- **Автоматическое чтение формы по ссылке** — сайты с логином недоступны; вопросы вставляешь ты.
- **Ответы на вопросы интервью** — отдельная тема (подготовка к интервью).

## User Stories
- Как кандидат, я хочу вставить вопросы формы одним блоком и получить по каждому 2–3 варианта
  ответа на английском, чтобы выбрать и скопировать.
- Как кандидат, я хочу, чтобы мотивационные ответы опирались на мою надиктовку письма и кейсы, а
  фактические — на мои стандартные данные.
- Как кандидат, я хочу задать лимит длины («до 500 символов»), если форма его требует.
- Как кандидат, я хочу видеть, из какой карточки взят каждый факт.
- *Крайний случай:* вопрос, на который в базе нет ответа (например, опыт в SQL) — агент честно
  пишет «в базе нет подтверждения» и предлагает вопрос для `case-interview`, а не выдумывает.

## Requirements

### P0
**P0-1. Блок «Вопросы формы»** в карточке вакансии: поле для вставки (по вопросу в строке),
опциональный лимит символов у вопроса, кнопка «Подготовить ответы».
**P0-2. Агент** (новый промпт `answers`): для каждого вопроса 2 варианта (короткий и развёрнутый),
только из `output/<…>/CV.md`, карточек, надиктовки письма и профиля. Результат —
`output/<…>/05-answers.md` + `05-answers.json` (вопрос, варианты, источники). Финальные варианты
проходят `scorer/check_humanize.py` (score ≤ 3).
**P0-3. Стандартные ответы** (notice period, зарплатные ожидания, локация и релокация, разрешение на
работу, языки) — файл `knowledge-base/profile-answers.md`, который ты заполняешь один раз;
агент берёт их оттуда дословно.
- ✅ Вопрос без подтверждения в базе получает пометку «нет данных» и не содержит выдуманных фактов.
- ✅ У каждого варианта — кнопка «Копировать» и счётчик символов.

### P1
- Библиотека повторяющихся вопросов: ответ, который ты отредактировал, сохраняется и
  переиспользуется в следующих заявках.
- Перегенерация одного ответа с комментарием («короче», «больше про LMS»).

### P2
- Распознавание вопросов из скриншота формы.

## Что уже есть в коде
- Промпты и запуск агента: `web/prompts.js`, `web/agent.js`; шаблон «фоновый агент без вопросов».
- Проверка машинности: `scorer/check_humanize.py`; правила тона: `.claude/skills/humanizer/SKILL.md`.
- Источники фактов: `knowledge-base/cards/`, `output/<…>/CV.md`, `00-dictation.md`.

## Success Metrics
- **Leading:** для ≥ 70% отправленных заявок с формой использованы ответы из приложения.
- **Lagging:** время на подачу (от «пакет готов» до «отправлено») сокращается; ноль ответов, где
  ты нашёл выдуманный факт.

## Решения и статус (2026-10-13)
- Скил `.claude/skills/form-answers/SKILL.md` (работает и в чате), фоновый промпт `answers`
  (`web/prompts.js`), `POST /api/vacancies/:name/answers`; вход `05-questions.json`, выход
  `05-answers.json` + `05-answers.md`; humanizer обязателен.
- Стандартные ответы — `knowledge-base/profile-answers.md`, редактор на экране Master CV.
  Языки, локация, формат и LinkedIn заполнены из Master CV; срок выхода, зарплата, виза — пусто.
- Мотивационные ответы — из кейсов голосом надиктовки, без порога 80%.
- Проверка на копии (Acme, 5 вопросов): лимиты соблюдены, факты без профиля → «нет данных»,
  SQL → «частично» с подсказкой для case-interview, humanizer 0/3, 80 с, ≈ $0.83.
- P1 (библиотека ответов, перегенерация одного ответа) — не сделано.

## Open Questions (исходные)
- *(ты, блокирующий)* Заполнишь `profile-answers.md` (notice period, зарплатная вилка, разрешение на
  работу в ЕС)? Без этого фактические вопросы останутся «нет данных».
- *(ты)* Мотивационные ответы — строго из надиктовки (как письмо, ≥ 80%), или можно из кейсов?
  Предлагаю: из кейсов, но голосом надиктовки, без порога 80%.

## P1 (2026-10-21)
- **Библиотека ответов** `knowledge-base/answer-library.json` (`web/answer-lib.js`): у варианта ответа «★ В библиотеку» (текст можно
  поправить прямо на месте). При «Подготовить ответы» вопрос, совпавший с библиотекой (≥ 60% значимых слов, ответ в лимите),
  отвечается дословно без агента; агент получает только остальные, результат склеивается в исходном порядке. Все совпали —
  агент не запускается. Список, правка и удаление — экран «Профиль».
- **«Переделать этот ответ…»** с комментарием — агент переписывает один вопрос (`05-answer-redo-N.json` → в `05-answers.json`),
  ≈ $0.3; остальные ответы не трогаются. `05-answers.md` пересобирается из JSON.
