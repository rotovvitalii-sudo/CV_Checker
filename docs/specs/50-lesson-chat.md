# C25 · Спросить Claude в уроке: выделил текст → объяснение в чате

**Приоритет:** Should · **Зависит от:** W8 (урок, панель темы `renderTopic`), C19 (курсы), S5 (журнал и бюджет агента)
**Оценка:** ~1,5–2 дня

## Problem Statement
Урок — это текст на 10–15 минут, и в нём регулярно попадаются места, которые с первого чтения непонятны: формула, термин,
шаг рассуждения («почему expected loss делится на базовую конверсию?»). Сейчас, чтобы разобраться, кандидат уходит в отдельный чат
Claude, копирует кусок, объясняет контекст урока заново — и теряет и нить урока, и ответ (он не остаётся рядом с уроком).
Нужен привычный по Claude жест: выделил фрагмент → «Объясни» → рядом открывается чат, который уже знает урок и курс.

## Goals
1. Из любого места урока за 2 действия (выделить → «Спросить Claude») открыть чат с цитатой и получить объяснение по контексту урока.
2. Можно продолжить разговор: уточнить, попросить пример, проще, по-другому.
3. Вопросы и ответы сохраняются при уроке — к ним можно вернуться при повторении.
4. Ответ опирается на урок и честно отделяет «в уроке этого нет — общее знание».

## Non-Goals
- **Общий чат вне обучения** — только уроки (и в P1 — разборы симуляторов и пояснения теста).
- **Агент с инструментами** (файлы, поиск по базе, правка урока) — чат только объясняет. Поиск источников — P1 по кнопке.
- **Влияние на «сдано»** — чат не меняет тест и статус темы.
- **Опыт для CV** — вопросы и ответы — учёба, в CV и письма не идут.

## User Stories
- Как кандидат, я хочу выделить фразу или формулу в уроке, нажать правую кнопку → «Объясни подробнее» и увидеть ответ в панели рядом, не уходя из урока.
- Как кандидат, я хочу выбрать готовое действие: «объясни проще», «приведи пример с числами», «как об этом спросят на интервью», «объясни по-русски».
- Как кандидат, я хочу написать свой вопрос к выделенному куску и продолжить диалог несколькими сообщениями.
- Как кандидат, я хочу задать вопрос по всему уроку без выделения («что здесь главное?»).
- Как кандидат, я хочу видеть у урока «Мои вопросы · N», открыть прошлый разговор и продолжить его.
- Как кандидат на телефоне, я хочу выделить текст и нажать появившуюся кнопку «Спросить» (правой кнопки там нет).
- *Крайний случай:* выделил текст вне урока (меню, кнопки) → браузерное меню как обычно, своего меню нет.
- *Крайний случай:* выделено очень много (больше ~1 500 знаков) → цитата обрезается с пометкой, вопрос всё равно уходит.
- *Крайний случай:* CLI не залогинен / бюджет исчерпан → панель открывается с понятной ошибкой и кнопкой «Повторить», а не молчит.

## Requirements
### P0
- **P0-1. Жест:** в тексте урока (EN и RU, урок вакансии W8 и урок курса C19 — общая панель `renderTopic`) выделение + правая кнопка →
  своё контекстное меню: «Объясни подробнее», «Объясни проще», «Пример с числами», «Как спросят на интервью», «Свой вопрос…».
  Вне текста урока и без выделения — обычное меню браузера. На сенсорных экранах при выделении появляется плавающая кнопка «Спросить» с тем же меню.
  Без выделения — кнопка «Спросить по уроку» в шапке урока.
- **P0-2. Панель чата:** справа от урока (на десктопе — боковая панель ~420 px, урок остаётся видимым; на телефоне — лист на весь экран):
  цитата сверху (свёрнута, если длинная), сообщения, поле ввода с микрофоном (`setupMic`), «Новый вопрос», закрыть. Ответ — markdown (формулы как текст),
  появляется потоком (как лента задач агента).
- **P0-3. Контекст ответа** (сервер собирает промпт, один ход без инструментов, как `fitquick`): название и цель курса / темы, текст урока (язык урока),
  раздел, где выделение, цитата, история разговора (последние ~10 сообщений), вопрос. Правила системного промпта: объяснять через урок и его термины;
  если ответа в уроке нет — сказать «в уроке этого нет» и ответить из общих знаний с пометкой; язык — русский, термины по-английски, как в уроке;
  коротко (до ~250 слов), с примером, где уместно; не выдумывать цифры из «реальных компаний».
- **P0-4. Модель:** задача `lessonchat` в `TASKS` (по умолчанию **Sonnet**, ≈ $0.01–0.03 за ответ; на экране «Агент» можно Haiku ≈ $0.002). Каждый ответ — в `runs.jsonl`
  и в бюджет S5. Задача не запускается, если CLI не залогинен (`agentReady`).
- **P0-5. Хранение:** `knowledge-base/learning/<slug>/chats/<id>.json` — `{id, created, lang, section, quote, messages: [{role, text, at, model, cost}]}`.
  У урока — «Мои вопросы · N»: список (цитата / первый вопрос, дата), открыть и продолжить, удалить.
- **P0-6. Безопасность:** цитата и вопрос — только текст; длина цитаты ≤ 1 500 знаков, вопроса ≤ 2 000; история в промпте — последние 10 сообщений;
  один ответ за раз на разговор (повторная отправка, пока идёт ответ, — 409).
- ✅ Выделение в уроке EN и RU → меню → ответ потоком в панели с цитатой; продолжение разговора учитывает прошлые сообщения; разговор сохраняется и
  открывается снова; вне урока — обычное меню; на телефоне — кнопка «Спросить»; без входа в CLI — ошибка и «Повторить»; smoke 0 ошибок.

### P1
- Тот же жест в разборах симуляторов (A/B, воронки) и в пояснениях неверных ответов теста («почему верно вот это?»).
- «Найти источники» — тот же вопрос с поиском (Sonnet с WebSearch, ≈ $0.1), ответ со ссылками.
- «Сохранить в урок» — ответ как заметка под разделом урока (видна при повторении `topicreview`).
- Подсветка в тексте урока мест, по которым уже спрашивал.

### P2
- Вопросы из чатов — в тест темы (то, что было непонятно, проверить в следующей попытке).
- Голосовой ответ (озвучка) для повторения в дороге.

## Success Metrics
- **Leading:** в уроках с вопросами доля сдачи теста с первой попытки не ниже, чем без них; среднее число вопросов на урок 1–3.
- **Quality:** ответ в среднем ≤ 250 слов, с пометкой, когда выходит за урок; 0 запусков без входа в CLI.
- **Цена:** ≈ $0.01–0.03 за ответ на Sonnet; ≤ $1 в месяц при 2–3 вопросах на урок.

## Решения (ждут «ок»)
- Модель по умолчанию — **Sonnet** (объяснения важнее экономии; Haiku — переключателем на экране «Агент»).
- Разговоры **сохраняются** при уроке.
- Поиск в интернете — **не в P0** (по кнопке в P1).

## Timeline
~1,5–2 дня: хранение и маршруты чата → промпт и задача `lessonchat` с потоком → контекстное меню и плавающая кнопка → панель чата (десктоп / телефон) →
«Мои вопросы» у урока → проверка в браузере.
