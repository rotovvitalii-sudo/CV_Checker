# C21 · Своё видео в уроке

**Приоритет:** Should · **Зависит от:** W8 (уроки и тесты по темам), C19 (уроки курсов — та же библиотека)
**Оценка:** ~0,5 дня

## Problem Statement
К уроку агент подбирает одно видео YouTube по фильтру профиля. Бывает, что оно не то (слабое, не про тот аспект), а
кандидат уже знает хорошее видео; бывает, что агент не нашёл ничего — и тест идёт только по уроку. Сейчас можно лишь
попросить агента «другое видео» (≈ $0.2, результат не управляем). Вставить свою ссылку нельзя. При этом вопросы теста
о видео строятся по `meta.json → video` — после любой замены они должны идти по новому видео, а не по старым ключевым мыслям.

## Goals
1. В уроке (и в вакансии, и в курсе) — «Вставить свою ссылку» рядом с «другое видео» и в состоянии «видео не найдено».
2. Своё видео проверяется и дополняется сервером без агента и бесплатно: oEmbed, длительность, дата, просмотры, описание, главы.
3. Следующий тест строится по текущему видео: его главы и описание, без ключевых мыслей прежнего.
4. Пересоздание урока и «другое видео» не теряют своё видео молча.

## Non-Goals
- **Не YouTube** (Vimeo, Loom, файлы) — не встраиваем и данных для вопросов не получаем. P2.
- **Субтитры как материал для вопросов** — сервер их не читает; вопросы по главам и описанию, как сейчас. P2.
- **Пересдача сданной темы из-за смены видео** — не требуем (см. Решения).

## User Stories
- Как кандидат, я хочу нажать «вставить свою ссылку», вставить `youtu.be/…` и сразу увидеть видео в уроке с длительностью и главами.
- Как кандидат, я хочу вставить своё видео, когда агент ничего не нашёл, чтобы 1–2 вопроса теста были по нему.
- Как кандидат, я хочу видеть предупреждение «длиннее 20 мин», но всё равно оставить своё видео — выбор мой.
- Как кандидат, я хочу, чтобы после замены видео незаконченный тест сбросился и новый был уже по новому видео.

## Requirements

### P0
1. **Ввод ссылки.** В блоке «Видео» урока: ссылка «вставить свою» (и при найденном видео, и при «не найдено»). Поле + «Поставить».
   Принимаются формы `youtube.com/watch?v=`, `youtu.be/`, `m.youtube.com`, `youtube.com/shorts/`, `youtube.com/embed/`, с `&t=` и прочими параметрами —
   сервер приводит к `https://www.youtube.com/watch?v=<id>`.
2. **Проверка — `POST …/topics/:slug/video/own`** (и для вакансии, и для курса; без агента, `agentReady` не нужен):
   - oEmbed отвечает → видео существует и встраивается; нет — отказ с причиной («видео нет, закрыто или запрещено встраивание»).
   - Сравнение названия не делаем (название берём из oEmbed).
   - Страница видео → `videoDetails` (длительность, дата, просмотры, язык, описание, главы).
   - Фильтр профиля (`video_rules`) **не блокирует**: промахи пишутся в `video.warnings` и показываются под видео
     («длиннее 20 мин (34 мин) — ты поставил сам»).
3. **Запись в `meta.json → video`:** `{url, title, channel, ...details, own: true, set_at}`; `key_points: []`, `source: "own"` —
   ключевые мысли прежнего видео не переносятся. `video_status: "ok"`. Прежнее видео агента — в `video_rejected` с причиной
   «заменено своим», чтобы агент не вернул его при поиске.
4. **Тест по актуальному видео.** При смене видео (своё, «другое видео», пересоздание урока) удаляется `test-current.json` —
   незаконченный тест был по старому видео. `topicTest` берёт материал из текущего `meta.video` (главы и описание со страницы).
   В `test-current.json` и в записи попытки `attempts.jsonl` пишется `video` (url) — видно, по какому видео сдавали.
5. **Своё видео не теряется:**
   - «Пересоздать урок»: агент переписывает `meta.json`; если до этого стояло своё видео — сервер возвращает его (агентские кандидаты — нет).
   - «другое видео» при своём — работает как сейчас (явный клик), своё уходит в `video_rejected` («заменено вручную»).
6. **Подписи в интерфейсе:** под своим видео — «твоё видео» и предупреждения фильтра; подпись про вопросы как сейчас
   («по главам и описанию будут 1–2 вопроса» / «нет глав и описания — вопросы только по уроку»). Если тема сдана —
   строка «тест сдан с прежним видео; пересдавать не обязательно».

### P1
1. «Вернуть прежнее» — одна ссылка, пока не сдан новый тест (прежнее видео хранится в `video_prev`).
2. Ключевые мысли своего видео по описанию и главам — Haiku один ход (≈ $0.001), чтобы показать «по ним будут вопросы».

### P2
- Vimeo / Loom; субтитры как материал теста.

## Success Metrics
- Своё видео ставится за < 5 с без запуска агента; в журнале запусков записей нет.
- Тест, составленный после замены, содержит вопросы с `from: "video"` по главам / описанию нового видео (при их наличии), ни одного по старому.

## Решения (2026-11-10)
Кандидат согласовал P0 с предложенными вариантами: своя ссылка — oEmbed + предупреждения фильтра; вопросы — по главам и описанию;
сданная тема остаётся сданной, сбрасывается только незаконченный тест.

## Open Questions (решены — см. «Решения»)
1. **Фильтр профиля для своей ссылки** — предлагаю: только предупреждение, не отказ (это осознанный выбор кандидата). Альтернатива — тот же жёсткий фильтр.
2. **Содержание для вопросов** — предлагаю: как сейчас, описание и главы со страницы; без глав и описания ≥ 200 знаков — вопросы только по уроку (это видно в подписи).
3. **Сданная тема при замене видео** — предлагаю: остаётся сданной (урок тот же, видео — 1–2 вопроса из 8); сбрасывается только незаконченный тест.
   Альтернатива — пометка «видео изменилось — пересдай» и снятие «сдано».

## Изменение (2026-11-14)
Тест больше не спрашивает по видео (см. W8), поэтому смена видео — своего или найденного — незаконченный тест не сбрасывает и предупреждения об этом нет.
