# Первое сообщение контакту

По воркбуку «Шлях самурая»: рекомендации дают ~1% заявок, но 17–18% наймов (данные Ashby). Незнакомый
человек не может за тебя поручиться, но согласиться на короткий разговор ему легко. Поэтому первое сообщение —
**начало разговора, а не просьба о работе**.

## Правила
1. **Три предложения, не больше:** кто я (одна фраза: роль + самый сильный факт под эту компанию) → почему пишу
   именно вам (роль человека, команда, вакансия, если есть) → один конкретный вопрос («что сейчас для команды
   важнее всего?», «как вам там?») и предложение 10–15 минут поговорить, если удобно.
2. **Запрещено:** просить работу, рекомендацию, «refer me», прикладывать CV, «are you hiring», общие комплименты.
3. **Факты** — только из `knowledge-base/base-cv.md` и карточек `knowledge-base/cards/`; ничего не выдумывать.
4. **Голос** — как в надиктовках `knowledge-base/raw/`: просто, по-человечески, без LLM-лексики (правила `humanizer`).
5. **Язык** — язык контакта из задачи (en / pl / uk / ru). Обращение — по имени, без «Dear».

## Результат
Файл, указанный в задаче: `{"message": "…", "language": "en", "facts_from": ["<файл базы>"]}`.
Проверь: `.venv/bin/python scorer/check_humanize.py --file <временный .md с текстом>` → score ≤ 3.
