# Humanizer

Задача — чтобы текст читался как написанный человеком, а не сгенерированный. Это редактура
формулировок, **не переписывание**: факты, цифры, структура и голос автора остаются.

## Жёсткие правила

1. **Ничего не добавлять и не выбрасывать по смыслу.** Меняются слова и пунктуация, не содержание.
   Ни одной новой цифры, ни одного нового утверждения.
2. **Голос автора важнее «гладкости».** Если у кандидата в тексте живой оборот — он остаётся,
   даже если звучит непривычно для делового английского. Шероховатость лучше стерильности.
3. **Для писем из `cover-letter`: пунктуация — моя, слова — его.** Тире, запятые и разбиение на
   предложения я расставлял при переводе устной речи, поэтому их можно править свободно. Слова
   менять только те, что я же и добавил (`[A]` в трассировке) или те, где перевод звучит по-машинному.
   После правок **перепроверить долю** `check_letter.py` — она не должна упасть ниже 80%.
4. **Не гнаться за нулём.** Цель — `score ≤ 3`, а не 0. Вычищать до стерильности — тоже признак
   машинной работы.

## Что чинить

| Признак | Что делать |
|---|---|
| **LLM-лексика**: delve, leverage, robust, seamless, holistic, foster, harness, unlock, elevate, spearhead, navigate the, embark | Заменить обычным словом: use, build, run, lead, start |
| **Шаблоны писем**: «I am writing to», «I am excited to apply», «passionate about», «proven track record», «perfectly aligns» | Выбросить целиком; на их месте — конкретика или ничего |
| **Вводные пустышки**: «It's worth noting», «It is important to note», «plays a crucial role» | Удалить, оставив сам факт |
| **Связки в начале предложения**: Moreover, Furthermore, Additionally, Ultimately, Overall | Удалить — почти всегда предложение работает без них |
| **Конструкции**: «not just X but Y», «whether it's… or…» | Переписать прямо |
| **Штампы**: cutting-edge, game-changer, ever-evolving, «in today's fast-paced world» | Выбросить |
| **Тире** более ~1.5 на 100 слов | Оставить одно (самое осмысленное), остальные → запятая, двоеточие, точка |
| **Перечисления «X, Y and Z»** три и более раз | Разбить или сократить одно |
| **Однообразная длина предложений** (σ < 5) | Добавить одно короткое предложение из 3–6 слов. Живой текст скачет по ритму |

## Процесс

1. Прогони проверку:
   ```
   .venv/bin/python scorer/check_humanize.py --file "<путь>"
   ```
2. Почини найденное по таблице выше. Правки — точечные, через Edit.
3. Перепрогони до `PASS` (`score ≤ 3`).
4. Если файл — сопроводительное письмо, перепроверь долю надиктовки:
   ```
   .venv/bin/python scorer/check_letter.py --trace "output/<...>/04-cover-letter-trace.md"
   ```
   Если правка меняла слова из `[D]`-предложения — обнови трассировку, чтобы она совпадала
   с финальным текстом.
5. Коротко отчитайся: что было найдено, что изменено, итоговый score. Если что-то осталось
   намеренно (живой оборот автора) — сказать об этом прямо.

## Чего не делать

- Не заменять его прямую речь на «правильный» деловой английский.
- Не добавлять «человечности» в виде разговорных вставок, которых он не говорил.
- Не переписывать предложение целиком ради одного слова.
